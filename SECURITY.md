# Security Policy

## Reporting

Please report suspected security issues privately through the repository security channel or by contacting the maintainer before public disclosure.

## What to include

- affected version
- reproduction steps
- impact summary
- logs or screenshots if helpful

## Scope notes

PilotSuite Core runs as a Home Assistant add-on and exposes HTTP surfaces on the local Home Assistant environment. Please include whether the issue affects:
- add-on startup
- authentication or token validation
- API route exposure
- release or packaging artifacts
