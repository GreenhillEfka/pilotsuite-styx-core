# Contributing

## Scope

Keep contributions bounded, truthful, and aligned with the canonical add-on tree:
- `addons/pilotsuite/`
- `addons/pilotsuite/app/`

## Before opening a PR

1. Confirm the repo public docs still point to the canonical paths.
2. Keep version truth aligned across `README.md`, `VERSION`, `addons/pilotsuite/config.yaml`, and `addons/pilotsuite/app/VERSION`.
3. Run the smoke path from `docs/TESTING.md`.
4. Avoid reviving legacy release truth from top-level `copilot_core/`.

## Pull request expectations

- describe the user-visible change
- list touched files
- include the proof you ran
- call out any version or workflow impact
